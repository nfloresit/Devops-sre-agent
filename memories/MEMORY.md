
# Entorno operativo

- Proyecto: MVP académico DevOps/SRE.
- Infraestructura: Google Cloud Platform.
- Sistema operativo: Ubuntu 24.04 LTS.
- Contenedores: Docker y Docker Compose.
- Framework agéntico: Hermes Agent.
- Modelo de lenguaje: Google Gemini mediante API.

# Contexto del proyecto

- El entorno se utiliza para pruebas controladas.
- Las alertas y métricas son simuladas.
- El caso de uso es el diagnóstico preliminar
  de incidentes operativos.

# Convenciones

- Identificación de incidentes mediante un ID.
- Clasificación de criticidad: baja, media,
  alta y crítica.
- Informes técnicos estructurados en español.

# Conocimiento adquirido

Sin aprendizajes operativos adicionales registrados
al inicio de la validación.
